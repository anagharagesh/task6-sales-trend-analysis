# Task 6: Sales Trend Analysis Using Aggregations

## Objective
Analyze monthly revenue and order volume using SQL aggregations.

## Tools Used
- SQLite
- DB Browser for SQLite

## Dataset
Online Retail dataset containing sales transaction data.

## Analysis Performed
- Calculated monthly revenue using SUM().
- Calculated monthly order volume using COUNT(DISTINCT order_id).
- Grouped data by year and month.
- Sorted monthly sales by revenue.
- Identified the top 3 months by sales.
- Analyzed sales for December 2010.

## SQL Concepts Used
- SELECT
- SUM()
- COUNT(DISTINCT)
- GROUP BY
- ORDER BY
- LIMIT
- WHERE

## Files Included
- task6_sales_trend_analysis.sql
- online_sales.db
- online_retail.csv
- Screenshots of SQL results
